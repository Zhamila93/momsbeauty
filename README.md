# Mom's Beauty — учёт подарочных сертификатов

Веб-приложение для сети салонов красоты: продажа подарочных сертификатов,
частичное погашение, отчётность по филиалам. Работает в трёх филиалах
ежедневно.

**Демо:** https://zhamila93.github.io/momsbeauty/

## Задача

До автоматизации сертификаты учитывались в тетради: номера дублировались,
остаток считали вручную, а погасить сертификат в филиале, отличном от места
продажи, было нельзя — данных там просто не было. Директор не видел общей
картины по сети.

## Возможности

**Продажа.** Номер присваивается автоматически, подряд, без возможности
пропустить или изменить его вручную. Записываются покупатель, получатель,
сумма, способ оплаты (Kaspi QR, БЦК, Halyk Bank, наличные), филиал и срок
действия.

**Погашение по частям.** Клиент может приходить несколько раз, пока не
израсходует номинал. Остаток пересчитывается автоматически, каждое списание
фиксирует услугу, филиал, администратора и время.

**Роли.** Директор видит сводный отчёт по сети, продлевает сроки, назначает
филиалы, увольняет сотрудников и выгружает данные. Администратор — только
продажа, погашение и поиск по номеру.

**Отчётность.** Непогашенная сумма, продажи и погашения за произвольный
период, разбивка по филиалам, по способам оплаты и по сотрудникам. Выгрузка
в CSV.

**Журнал действий.** Все операции, включая продления сроков и изменения
доступов, записываются с именем сотрудника и временем. Записи нельзя
изменить или удалить.

## Технические решения

**Защита от двойного списания.** Погашение выполняется функцией в PostgreSQL
с блокировкой строки (`SELECT ... FOR UPDATE`). Если два филиала пытаются
списать средства с одного сертификата одновременно, второй запрос получает
отказ с актуальным остатком — списать больше, чем есть, невозможно.

**Роли на уровне интерфейса и данных.** Администратор не видит разделов,
которые ему недоступны, а серверные операции проверяют роль повторно.

**Хранение паролей.** Пароли не хранятся в открытом виде: в базе лежит хеш
SHA-256 с индивидуальной солью. Директор может сбросить забытый пароль,
программа выдаёт временный, который сотрудник меняет при первом входе.

**Синхронизация между филиалами.** Приложение опрашивает базу и обновляет
экран только при изменении данных — перерисовка не сбрасывает ввод и не
мешает работе.

## Стек

- Frontend: HTML, CSS, JavaScript без фреймворков — один самодостаточный файл
- Backend: Supabase (PostgreSQL, REST API, функции на PL/pgSQL)
- Хостинг: GitHub Pages

## Запуск

Приложение не требует установки: открывается по ссылке в браузере,
на телефоне добавляется на домашний экран как обычное приложение.

Для развёртывания своей копии нужны проект Supabase с таблицей `mb_docs`
и функцией `mb_redeem`, а также подстановка URL проекта и публикуемого
ключа в начало `index.html`.
